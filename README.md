# NavigoJobs — საზღვაო კარიერის პლატფორმა

NavigoJobs არის საზღვაო დასაქმების პლატფორმის ვებგვერდი. მეზღვაურები ეძებენ ვაკანსიებს და აგზავნიან სარეგისტრაციო განაცხადს, საკადრო სააგენტოები და გემთმფლობელები კი არეგისტრირებენ კომპანიას და აგზავნიან ვაკანსიებს.

**საიტი:** [georgee-21.github.io/navigojobs](https://georgee-21.github.io/navigojobs/)

**ტექნოლოგიები:** HTML5, CSS3, JavaScript. პროექტს არ სჭირდება ბილდი, `npm` და ბიბლიოთეკები.

> ეს არის სასწავლო პროექტი. ვაკანსიები, სტატისტიკა და საკონტაქტო მონაცემები საჩვენებელია. სერვერი და მომხმარებლის ანგარიშები არ არის, ფორმები კი Formspree სერვისით იგზავნება.

## ფუნქციები

- **ორი ენა:** ქართული და ინგლისური. არჩეული ენა გვერდებს შორის გადასვლისას ინახება.
- **ორი თემა:** მუქი და ღია. არჩევანი ინახება `localStorage`-ში.
- **ვაკანსიების ძებნა და ფილტრი:** ძებნა რანგით, გემით, ზონითა და სააგენტოთი, ფილტრი დეპარტამენტის მიხედვით. ფილტრი URL-შიც ჩანს (`jobs.html?dept=DK`).
- **განაცხადი ვაკანსიიდან:** ვაკანსიის ბარათი ხსნის რეგისტრაციის ფორმას, სადაც რანგი და გემის ტიპი უკვე შევსებულია.
- **ფორმები:** HTML5 ვალიდაცია, გაგზავნის სტატუსი და შეცდომის შეტყობინება.
- **რესპონსიული დიზაინი:** Grid და Flexbox, მობილურზე burger მენიუ.
- **ხელმისაწვდომობა:** სემანტიკური ტეგები, `label for`, `aria-*` და მთავარ შინაარსზე გადასვლის ბმული.

## გაშვება

გახსენი `index.html` ბრაუზერში ან გაუშვი პროექტი VS Code-ის **Live Server** გაფართოებით. ფორმების შესამოწმებლად Live Server გამოიყენე.

## სტრუქტურა

```
index.html               — მთავარი გვერდი
jobs.html                — ვაკანსიები: ძებნა და ფილტრი
contact.html             — საკონტაქტო ინფორმაცია და რუკა
register-seafarer.html   — მეზღვაურის რეგისტრაცია
post-job.html            — ვაკანსიის განთავსება
register-company.html    — კომპანიის რეგისტრაცია
privacy.html             — კონფიდენციალურობის პოლიტიკა
404.html                 — "გვერდი ვერ მოიძებნა"
sitemap.xml              — გვერდების სია საძიებო სისტემებისთვის

css/
  style.css              — თემა, ტიპოგრაფია, ღილაკები, ნავიგაცია, ფუტერი, ფორმები
  home.css               — მთავარი გვერდი
  jobs.css               — ვაკანსიების გვერდი
  contact.css            — კონტაქტის გვერდი

js/
  translations.js        — ქართული და ინგლისური ტექსტები
  data.js                — დეპარტამენტები, ვაკანსიები, ეტაპები
  main.js                — ზედა ზოლი, ნავიგაცია, ფუტერი, ენა, თემა, მობილური მენიუ
  home.js                — მთავარი გვერდის ბარათები და ვიდეო
  jobs.js                — ვაკანსიების ძებნა, ფილტრი და ბარათები
  forms.js               — ფორმების გაგზავნა და ველების შევსება

assets/
  images/                — ფოტოები
  video/                 — მთავარი გვერდის ფონური ვიდეო
```
